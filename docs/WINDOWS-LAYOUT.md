# Windows 11 标准任务管理器布局

日期：2026-10-24。用户要求“必须完全按 Windows 标准任务管理器的布局，每个页面都是”。本增量以 Windows 11 左侧导航版本为布局基准，覆盖进程、性能、应用历史记录、启动应用、用户、详细信息、服务、设置全部八页，优先于旧文档允许的卡片化、资源横向类别页签、多层操作栏和常驻底部状态栏。Windows 10 是运行平台，界面仍统一使用此版本的布局。

这里要求的是页面结构、位置、层级、密度和操作区一致。字段和操作继续服从真实 Windows 数据合同：不能把 I/O 改名“磁盘”，不能把会话观测改成系统完整历史，不能为复刻外观编造发布者、启动影响、GPU 内存、网速或未实现按钮。React/Tailwind/Electron.NET、CsWin32、JSON.NET、管理员入口、共享搜索和现有身份保护均保留。

## 2. 统一外壳与几何

所有尺寸为100%应用缩放下 CSS px，对应 Electron 客户区 DIP；不把物理显示器像素当作 CSS px。

```text
┌────────── 图标 Takao ─────── 共用搜索 ─────────── 最小化/最大化/关闭 ┐
│ 菜单 │ 当前页标题                               本页命令 ···          │
│ 进程 │──────────────────────────────────────────────────────────────│
│ 性能 │                                                              │
│ 历史 │        该页标准内容区：数据表 / 资源列表+图 / 设置表单            │
│ 启动 │                                                              │
│ 用户 │                                                              │
│ 详情 │                                                              │
│ 服务 │                                                              │
│      │                                                              │
│ 设置 │                                                              │
└──────┴──────────────────────────────────────────────────────────────┘
```

- 顶栏48px，左侧应用图标20px和“Takao”13px；去掉版本徽标。搜索居中，宽400px、最高480px、高32px；窄窗可缩到240px。窗口按钮46px宽，保持真实 Electron 行为和拖动区域排除。
- 左导航宽204px、折叠48px。菜单按钮48px区，导航项40px高、上下间隔4px、左右留白4px，图标20px、标签13px；顺序固定进程/性能/应用历史记录/启动应用/用户/详细信息/服务，设置固定在底部。不增加“本机·Windows”页脚。
- 1008px及以上优先展开，低于1008px自动compact；手动折叠偏好继续有效。960×640仍是桌面左导航，不切成顶部页签或移动导航。
- 右侧主面板白色、左上圆角8px、其余按窗口边界裁切；命令栏56px，左右24px，标题20px semibold，主命令透明/低对比边界的 Windows 平面样式，高32px。结束任务不在正常态用大红块；破坏性确认内仍使用 danger。
- 每页只有一个标题和一条命令栏。进程筛选/树模式/列/导出/冻结、表页重置、数据来源说明等放“更多”或表头菜单；移除常驻 `page-actions`、`process-controls`、`selection-strip` 和大段 `page-note`。已选目标通过行选中与详情表明，详情入口必须保留在命令或更多中。
- 不保留正常状态的底部全宽连接条。正常连接/最后采样/间隔放命令栏更多中的“采样状态”，可用12px紧凑状态文字辅助；暂停、冻结、断连、过期、保存失败必须在页头下方出现非装饰性 InfoBar，并显示真实时刻/恢复或重试。正常态没有空白占位条。
- 表头固定在表格滚动区顶部：带资源汇总的进程/用户为58px，普通历史/启动/详情/服务为36px；紧凑行32px、标准行40px。表占满可用区域，只有表格自身水平滚动。禁止以居中小卡片、分组卡片、指标卡带替代数据表。
- 主区无文档级横向溢出；窄窗命令按重要性移入更多，命令栏不换成两行，不移走唯一“结束任务”入口。主标题不重复，不通过缩小到12px以下解决空间问题。

## 3. 八页逐页合同

以下列顺序为新安装/恢复默认的顺序。列宽偏好、全部列排序、拖动/键盘/点击式调宽、虚拟化和稳定 identity 必须继续有效；旧配置保留已选字段和宽度，不能为迁移清空用户偏好。名称/PID不可隐藏的既有约束继续适用。可选列仍通过显示列访问。

| 页面 | 命令栏（从左至右位于标题右侧） | 主内容及默认列顺序 |
|---|---|---|
| 进程 | 运行新任务、结束任务、效率模式、更多 | 全宽资源表；名称、状态、CPU、内存、I/O、网络、GPU、PID。CPU/内存/GPU表头上行显示真实整机汇总；I/O不借用物理磁盘汇总，逐进程网络仍为缺失原因。树/平铺保持为更多中的视图选择，不占第二行。名称含真实图标/树箭头；不推断“应用/后台/Windows”分类。 |
| 性能 | 运行新任务、更多 | 固定左列逐资源磁贴，右侧标题/大图/统计。完整规格见第4节。不得出现横排CPU/内存/网络/磁盘/GPU类别按钮。 |
| 应用历史记录 | 运行新任务、清除本次统计、更多 | 命令栏下仅一行“小字：本次会话起于实际时间”，全宽普通表头；名称、观测CPU时间、I/O读取累计、I/O写入累计、PID、状态、最后观测。更多含定位仍运行进程/重置/统计口径，不显示虚构网络/计费网络/磁贴更新列。 |
| 启动应用 | Windows启动应用设置、更多 | 全宽普通表头；名称、启用状态、来源、启动命令/路径、可定位来源。不增加假发布者/启动影响/最后BIOS时间。启用状态必须使用现有未知说明；本应用未提供策略写入，不画假启用/禁用操作。更多含复制命令、打开来源、当前/公共Startup文件夹、重置。选中内容移入按需详情，不能常驻在表下占一大块。 |
| 用户 | 查看此会话的进程、更多 | 全宽资源表；用户、状态、CPU、内存、会话ID、会话名称、进程数。CPU/内存可用真实系统汇总作表头，行值仍按可确认会话归属聚合。真实会话名与ID可选，不伪造注销/断开按钮和进程展开数据；查看会话保留现有真实跨页定位。 |
| 详细信息 | 运行新任务、结束任务、更多 | 全宽平铺普通表头；名称、PID、状态、用户、CPU、内存（工作集）、优先级、线程、父PID、会话、映像路径。其余原生字段保留可选列；不显示树模式按钮，不在本页伪造“描述”字段。 |
| 服务 | 启动、停止、重启、更多 | 全宽普通表头；名称、PID、显示名称、状态。更多含服务详情、定位关联进程、打开Windows服务管理器、重置。主动作使用同一固定服务对象和现有详情/确认工作流，异步读取权限/状态后才可操作，不直接信慢快照；权限/目标变化与超时恢复沿用已验证语义。 |
| 设置 | 无运行新任务按钮；可有更多/帮助 | 单一“设置”页头，下方纵向滚动的 Windows 设置行/分组，文字左、控件右。不得出现营销标题、重复h2、英雄图或能力卡片墙。见第5节。 |

无可用选择时，目标动作禁用并有可获取的原因。更多里的非目标视图操作仍可用，不能因没有选中行将整个更多按钮禁用。效率模式读取/切换沿用真实支持、目标身份与恢复基线合同；标题栏上的按钮只是既有真实动作的新入口。

## 4. 性能页

这是本轮结构修正的重点。内容区本身左右两列：资源磁贴列220px（窄窗184px）+右侧 `minmax(0,1fr)`，不再在不同资源类别中新增或撤销一层侧栏。

1. 左列顺序固定为CPU、内存、每个实际磁盘、每个实际网络适配器、每个实际GPU；同类设备稳定排列。每条均为可选择按钮，左侧64×40px小曲线，右侧名称和当前真实数值；普通条目高72px。磁盘条目需容纳名称、类型/总线和两行读/写速率，最小高度为既有条目高度加space-6（96px），内容可自然增高，避免文字重叠或裁切。选择底色用 selection，圆角4px。CPU/内存也在此列，不能只有外设有选择列表。
2. CPU磁贴显示CPU及当前使用率；内存显示已用/总量和百分比；磁盘显示实际实例名、已知类型/总线及读取/写入速率，小曲线采用读/写双线；网络显示真实alias及收/发速率；GPU显示Windows实际描述和最忙引擎百分比。没有Windows编号来源时不猜“GPU 0”或磁盘型号；长名称省略并保留可访问全名，LUID等技术标识放详情事实或tooltip。
3. 小曲线和右侧主图都只来自当前 `performanceHistory` 中真实时间点，最多120个；按独立资源ID/实际来源时刻取值，预热为空、null/断流断线、不造历史、0可显示。资源未读到时只保留一个明确“磁盘/GPU：正在初始化/不可用”条目，不虚构设备数量与身份。真实无匹配用共享搜索空态。
4. 右侧标题行：左CPU/内存/磁盘/网卡/GPU资源名，右真实设备描述（已有来源才显示）；大图在下方，网格/坐标/单位清楚；CPU/内存主图目标高度280px（窄窗220px）。磁盘只保留一张读取/写入吞吐图，读取/写入用实/虚线且单位为字节/秒；活动时间数值、活动曲线及其图例不再展示。网络收发用实/虚线；GPU只有已接入最忙引擎图，不伪造3D/Copy/Encode等四宫格。
5. 图下为无卡片边框的原生统计排布：CPU使用率、逻辑处理器、进程/线程/句柄、运行时间；内存已用/可用、提交/限制、缓存/总量；磁盘读写速率/型号/类型/总线/身份；网络收发/真实链路/接口信息；GPU描述/LUID/引擎/软件标志。以两到三列紧凑事实展示，重要数值24px，标签12px；无巨型百分比浮在右上角。
6. 技术来源与统计口径收进更多的资源说明或事实区末尾可展开说明；可读值的正常页面不常驻几段技术警告。指标不可用原因仍紧邻对应字段或图，不隐藏错误。
7. 左资源列和右详情独立垂直滚动；切资源保留既有偏好。共享搜索按现有类别/设备规则过滤磁贴，临时回退不覆盖原资源偏好，清空恢复；无需额外轮询或采集。

图表当前配色以 [CHART-PALETTE.md](CHART-PALETTE.md) 为准：主图、逐CPU图和磁贴小曲线统一白底、中性浅灰网格/边界；主线蓝色实线，次线深灰虚线，图例与当前值明确。以上布局、线型、资源状态和单位规则继续适用。

## 5. 设置页

- 顶部只有统一“设置”页头，正文左右24px留白，表单最大宽960px，靠左而非整页居中。
- 首组为“常规”：更新速度、自动采样、冻结列表显示、始终置顶、界面缩放；次组为“视图”：密度、默认进程视图、折叠侧栏；使用现有真实控件，不新增未实现的主题/默认开始页/托盘开关。
- 后续“任务管理器入口”“偏好与帮助”“关于/本机数据来源”“能力与采集边界”。每项56px起高、标题13px、说明12px、右侧控件；多行说明可增高，段间24px。入口接管继续完整显示范围/管理员/移动删除前取消等必要说明和真实状态。
- 版本/来源为紧凑定义列表；能力为紧凑行，可展开，不占据首次进入的大半屏。保留共享搜索可发现的全部现有文本，不能因折叠将命中条目隐藏；IFEO组件筛选时不卸载、不重读或重放写操作。
- 置顶/缩放仍依赖实际窗口读回；headless明确禁用。暂停采样和冻结显示分开，不能仅为贴近系统外观而合并。

## 6. 实施顺序与回归

阶段2仅由一个界面代理写业务代码：先统一Token/外壳/命令栏，再逐页表格默认列/更多动作，随后性能资源列与设置。复用现有DataTable/ContextMenu/详情对话框和API，不为布局重写原生采集器；仅当新入口确实需要共享已存在的动作状态时抽取可复用组件/回调。

阶段3由独立验收代理运行生产构建与真实Windows/Electron链路，逐页保存空搜索下1380×860和960×640截图；125%实际Electron缩放、reduced-motion、键盘、全部列调宽排序、共享搜索、真实测试身份操作一并回归。L系列定义在 [ACCEPTANCE.md](ACCEPTANCE.md)，旧结果仅是回归背景。

此次新增标准布局不能被只改背景颜色、只改进程页、只隐藏工具栏或替换为伪数据截图视为完成。若权限阻止Electron或真实写动作，记录具体未执行项并保留可复现命令。
