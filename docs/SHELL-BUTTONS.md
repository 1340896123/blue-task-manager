# 导航与页头命令按钮

日期：2026-11-08。适用Qt 6 Widgets + .NET10当前桌面，按用户截图标注调整左侧导航和右上页头命令。第二张图片仅参考小圆角按钮形态，颜色以用户明确要求的灰底黑字为准。

## 范围与行为

- 左侧各页导航及底部设置复用一套等高、等宽、灰底黑字圆角按钮；收起状态继续显示同族图标、完整名称提示与可访问名称。选中使用现有蓝色指示与明确状态，键盘焦点独立可见。
- 页头的运行新任务、结束任务、详情、暂停/继续采集、刷新/正在读取、更多、复制/已复制和已有页面专用命令统一实际宽高、灰底、黑字及图标。覆盖这些区域原蓝色主按钮、红色结束文字和透明命令样式。
- 页头最长常见标签“运行新任务”保留；长专用命令可用“清除统计 / 启动设置 / 服务管理器”，完整原用途保留于accessibleName/tooltip。已有清除统计、终止等安全确认、真实身份保护、禁用原因和忙态继续适用。
- 复制仍完整复制真实硬件快照，按钮短暂显示“已复制”且边界不动；暂停/继续和刷新忙态也不改变尺寸。所有图标有实际含义、统一20px/约1.7px线宽，沿用现有矢量缓存；装饰图标由可见文字提供语义，不能以emoji替代。
- 样式仅应用在上述导航/命令区域，现有设置卡片内部、弹窗、表格及其它控件保持各自合同；无需新增API、采集、JSON或系统写入。

## 尺寸与布局

具体Token以MASTER顶部为源：共用44px高度、4px圆角，命令目标宽120px；当前字体放大时按最长常见标签+图标+内边距统一增宽增高。导航展开宽度沿用204px侧栏的内容宽，收起宽度沿用56px侧栏，不把导航宽度套给命令。

六个120px命令加48px间距和56px进程标题共824px，可放入默认1100宽窗口约848px内容区；命令水平padding应计入图标与标签总宽。最小960宽的内容约708px，不能强塞六个120px按钮；优先只将“详情”移入现有“更多”，五按钮加间距及标题约696px。字号放大时若仍不足，再按实际空间收纳必要次动作，复用原槽、状态与完整可访问标签；足够宽时恢复原命令，自动布局不改用户偏好。已有“更多”有导出/列/统计/系统入口；若临时收纳详情或暂停，须接入其现有动作与禁用状态。保持一条页头和稳定标题，不引入新的响应式框架。

## 成熟实现与技能

已实际读取 [Qt QPushButton固定源码](https://github.com/qt/qtbase/blob/feb9556bde250306b5a1157aaccb76106844909e/src/widgets/widgets/qpushbutton.cpp)，采用标准QPushButton/QIcon/QStyle尺寸及集中QSS，保持原生键盘和可访问性。`Theme::icon()`已是同族缓存矢量图形，仅补缺失命令，不引入新图标库。UI/UX技能按桌面适用规则使用既有字体、正文对比≥4.5:1、图标/焦点≥3:1、可见禁用状态与顺序键盘；查询取舍见RESEARCH。用户指定灰底黑字覆盖旧主/危险命令配色，未取消确认保护。
