# 全页网格：列宽与排序

2026-10-23 用户增量：每个已有数据网格允许拖动列宽，点击任意列头可排序。本规格补充 PRD/ARCHITECTURE，不改变真实 Windows 数据、同源 HTTP、JSON.NET 与管理员边界；研究来源见 [RESEARCH.md](RESEARCH.md)。

## 覆盖范围

全部网格统一使用现有 `DataTable`，不新增表格依赖。性能页资源图/事实列表、设置表单、详情概览及关联服务按钮列表不属于数据网格，不为本需求新增表格。

| 网格 / 位置 | 必须支持排序与调宽的列 |
|---|---|
| 进程、详细信息 / `process/ProcessWorkspace.tsx` | 全部可显示列：名称、PID、状态、父PID、会话、线程、句柄、优先级、CPU、工作集、专用提交、I/O、网络、GPU、GPU引擎、用户、发布者、映像路径 |
| 应用历史记录 / `PageWorkspace.tsx` | 名称、PID、状态、观测CPU时间、I/O读取累计、I/O写入累计、最后观测 |
| 启动应用 / `PageWorkspace.tsx` | 名称、来源、启用状态、启动命令/路径、可定位来源 |
| 用户 / `PageWorkspace.tsx` | 用户、会话ID、会话名称、状态、进程数、CPU、内存 |
| 服务 / `pages/Services.tsx` | 名称、显示名称、状态、PID |
| 进程信息 TCP/UDP / `process/ProcessDetail.tsx` | 协议（含地址族）、本地端点、远端端点、状态 |

## 行为合同

1. 列头右边界有独立调整柄及 `col-resize` 光标；按下、拖动、释放调整当前列，包括最后一列。使用标准 Pointer Events/pointer capture，移出表头仍可结束；取消、页面切换、卸载时释放。拖动不得冒泡为排序或行激活，也不得选中文字。
2. 标题、`colgroup` 与数据单元格使用同一列宽状态，按 CSS 像素计算。改变一列不得按比例缩放其他列；总宽随列宽变化，超出时只在网格容器水平滚动。宽度有界，默认来自现有 MASTER；实时采样与虚拟行更新不得重置宽度、丢失调整动作或改变选择身份。
3. 调整柄可键盘聚焦，左右方向键调整，提供当前宽度与列名的可访问说明。还提供可点击的列宽设置（输入或加减按钮）和恢复默认宽度入口，使拖动有单指针替代操作；双击调整柄可快捷重置。焦点/悬浮/正在调整用已有 Windows 蓝色 Token。
4. 每个数据列头使用真实按钮和 `aria-sort`；首次点击新列升序，再次点击在降序/升序间切换。Enter/Space 等效。全为未知的列也能切换排序方向，保持稳定行序；不得为排序制造业务值。
5. 排序使用原始数值/BigInt/时间戳与复用的 `Intl.Collator('zh-CN', { numeric: true })`，不排序带单位的格式化字符串。状态使用一致可解释的显示值，优先级使用实际优先级顺序；连接端点按地址、数字端口比较。`null`/不可用/不适用始终放末尾，升降序均不得当作0；同值保持稳定顺序（进程以真实身份/PID为稳定次序）。
6. 进程树只对根与同级子节点排序，保留父子层级、折叠与筛选祖先上下文。排序后滚回表内顶部，选择仍基于 identity；菜单/详情不得改为排序后另一条记录。详情连接表在真实刷新后继续使用用户的排序/列宽。
7. 主导航各页列宽独立持久化，跨页/重启恢复；隐藏列重显保留其宽度。页面重置恢复列宽默认值，全局偏好重置同时清除列宽。详情连接表可保存在当前对话框会话，不要求写主导航偏好。

## 偏好与实现边界

- 为 `PagePreference` 增加可选 `columnWidths` 字典（列key → CSS像素数），缺失或null沿用默认，兼容现有version 1配置；前后端类型、默认值、JSON.NET模型及验证同步。列白名单补齐启动页 `location` 等实际列。
- 字典最多40项，仅允许实际列key、有限数值，保存范围64～1600像素；具体列可有更高的语义最小值。非法配置遵循现有显式警告/安全默认，不能导致无限宽或原型属性注入。
- 拖动期间尺寸保留在局部视图状态，落盘只在完成后经既有防抖保存；键盘/设置入口同样复用该保存链路，不每次pointermove发请求。
- 保留 TanStack Virtual 的有界渲染；只抽取共用列宽交互和排序比较能力，不迁移框架、不新增数据源/私有协议。不降低管理员门槛来运行E2E。

验收采用 [ACCEPTANCE.md](ACCEPTANCE.md) G01～G07，结果写入独立可复现报告并引用截图路径；不能用构建成功替代真实 UI 与 Electron 验证。
