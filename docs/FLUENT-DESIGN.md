# Takao Fluent 桌面设计规范

日期：2026-11-04。适用实现：Qt 6.8.3 Widgets / C++17 + .NET 10。状态：实施规范，运行验收结果另记；本文件不宣称八页已完成调整或通过测试。

## 1. 目标、范围与优先级

以 Windows 11 的 Fluent / WinUI 视觉习惯调整全部八页，使用户快速找到真实资源、选中目标并理解操作结果。采用清晰字阶、中性浅色分层、蓝色强调、轻描边和稳定的桌面信息密度。保留 Windows 11 任务管理器式左导航、共用搜索、单一页头/命令栏和 Qt 原生 model/view；设置采用分组 SettingsCard 的行为与布局习惯。

本规范与 [MASTER](../design-system/takao/MASTER.md) 顶部 Fluent 映射共同覆盖下方旧视觉数值及同日早先 Qt 映射；数据语义、API、排序/列宽、偏好与安全合同仍以 [QT-MIGRATION.md](QT-MIGRATION.md)、[API.md](API.md) 及对应功能规格为准。历史 Electron、React、CSS 与旧分辨率章节只作为记录。这里的 Fluent 是 Qt Widgets 的视觉与交互映射，不代表改用 WinUI，也不承诺系统 Mica/Acrylic 材质、WebView 或 WinUI 动画运行时。

- 八页：进程、性能、应用历史记录、启动应用、用户、详细信息、服务、设置；保留现有可用动作、菜单、详情、快捷键和身份保护，不增加无后端能力的入口。
- 真实 Windows → CsWin32 → .NET / JSON.NET → 既有回环 HTTP/JSON → Qt 的链路保持；禁止模拟列表、数值、曲线和成功结果，未知不能转换为 0。
- 显示验收只执行 **1920×1080 可见窗口画面物理像素、100%测试缩放**；不执行其他分辨率、125%、手机或暗色主题矩阵。保留已有文字大小、窗口与密度偏好能力，不以该测试范围移除功能。
- 开发按阶段由多个代理顺序完成，同一时间只有一个阶段代理写业务代码；每阶段检查后独立提交。验收操作仅结束本次创建并核对身份的专用进程。

## 3. 语义 Token

所有值集中在 `src/Takao.Qt/Theme.h` 或其统一主题模块，QPalette、QSS、delegate、图表读取同一语义；页面仅引用角色，不散落色值、字号和圆角。旧 `border` 拆为装饰分隔、控件轮廓和关键边界，避免全部控件画成重灰框。

| Token | 浅色值 | 用途 |
|---|---|---|
| `window` / `navigation` | `#F3F3F3` / transparent | 窗口、导航底；原生标题栏遵循 Qt/Windows |
| `content` / `surface` / `surfaceSubtle` | `#F9F9F9` / `#FFFFFF` / `#F6F6F6` | 内容背景、表格/卡片、分组/表头 |
| `strokeSubtle` / `strokeControl` | `#E5E5E5` / `#D1D1D1` | 面板1px分隔、控件轻轮廓；不单独承担状态含义 |
| `strokeKeyline` | `#8A8A8A` | 输入框底边/必要控件边界，保证关键轮廓可辨 |
| `textPrimary` / `textSecondary` | `#1A1A1A` / `#5F5F5F` | 正文与说明；次级文字仍须≥4.5:1 |
| `textDisabled` | `#747474` | 真正禁用的控件文本；禁用语义和原因同时保留 |
| `accent` / `accentHover` / `accentPressed` | `#0067C0` / `#005FB8` / `#00539F` | 主动作、指示条、链接；蓝底配白字 |
| `hover` / `pressed` | `#EDEDED` / `#E4E4E4` | 中性按钮、导航、可交互行反馈 |
| `selection` / `selectionHover` | `#E8EEF5` / `#DEE8F2` | 表格/资源选择；导航使用中性 `hover` 选中底 |
| `focus` | `#005FB8` | 2px键盘焦点，独立于hover与选择，不改变控件几何量 |
| `success` / `successSurface` | `#107C10` / `#DFF6DD` | 真实操作成功、已启用；同时有文字/图标 |
| `warning` / `warningSurface` | `#8A4B00` / `#FFF4CE` | 未知、过期、部分读取；保留具体原因 |
| `danger` / `dangerSurface` | `#A4262C` / `#FDECEE` | 失败、破坏性确认、字段错误 |
| `info` / `infoSurface` | `#005FB8` / `#E8EEF5` | 暂停、冻结、来源提示 |
| `chartSurface` / `chartGrid` | `#FFFFFF` / `#ECEFF2` | 图表白底、装饰网格 |
| `chartPrimary` / `chartSecondary` | `#0067C0` / `#58636F` | 主序列实线、次序列虚线，图例同步 |

普通文本与实际背景对比≥4.5:1；承载信息的图标、焦点、关键边界和曲线≥3:1。装饰网格/分隔不按关键边界误判，也不能承担唯一信息。热度仅使用蓝色低透明度叠层，最大16%；不覆盖选择/焦点，不把未知画成零热度。需记录实际合成色的对比度，而不只检查 Token 字符串。

## 4. 字体、空间与布局尺寸

字体优先 `Segoe UI Variable Text`，其次 `Segoe UI`；中文由系统 `Microsoft YaHei UI` 回退。Qt 使用本机字体与 fallback，不下载网络字体。表格与事实数字使用等宽数字；若系统字形不支持，数值列采用本地 `Cascadia Mono` / `Consolas`，中文标签仍用系统 UI 字体。

| 字体角色 | 字号 / 行高 / 字重 | 使用 |
|---|---|---|
| `caption` | 12 / 16 / 400 | 单位、时间、辅助说明；不低于12px |
| `body` / `bodyStrong` | 14 / 20 / 400、600 | 表格、按钮、输入、设置项标题 |
| `bodyLarge` | 16 / 24 / 400 | 对话框引导、重要说明 |
| `section` | 20 / 28 / 600 | 设置分组、详情章节 |
| `pageTitle` | 28 / 36 / 600 | 八页唯一主标题 |
| `resourceTitle` / `metric` | 32 / 40 / 600 | 性能资源名称、关键数值；单位14px |

所有尺寸为100%测试缩放时 Qt 逻辑像素；不得混用 pt 与 px。自定义文本按字体度量计算所需高度，不能用固定行高裁切中文。间距统一 `4, 8, 12, 16, 24, 32`，正文说明换行且与控件不重叠。

| 几何角色 | 规定 |
|---|---|
| 应用顶部区 | 内容高56px；品牌区与左导航对齐，共用搜索宽480px、高36px；采样摘要可读，非按钮外观 |
| 左导航 | 展开204px、收起56px；内边距8px；导航命中高44px、项间4px；底部设置与更新入口保留 |
| 内容区 | 左右24px、顶部16px、底部24px；仅一个标题/命令栏，栏最小高56px，内容间16px |
| 命令 | 主要动作高44px；命令栏和模态主动作均44px；紧凑辅助控件/更多菜单项可32px，横向间隔8px；图标命中区44×44px |
| 表格 | 紧凑32px/标准40px数据行；当前普通列头40px必需；如增加资源汇总双层列头则64px，必须使用同帧system的已有真实业务来源，不扩采或虚构字段；水平单元格内边距12px；自有横/纵滚动 |
| 控件 | 输入/选择器常规高36px；圆角4px；焦点使用内绘或预留轮廓空间，出现焦点不挤动布局 |
| 面板/弹层 | 圆角8px，1px轻描边；卡片不加常驻阴影；菜单/对话框可用轻阴影体现层级，不能遮蔽文本 |
| 性能资源栏 | 宽240px、与右区间16px；普通磁贴最小80px，磁盘双速率最小96px；资源选中底+指示，不做重边框卡片墙 |
| 设置 | 内容最大1080px，靠左并与页标题对齐；组间24px，组标题下12px，同组卡片间4px；行最小76px、内边距16px、说明区与控件间24px |
| 设置控件 | 右侧普通选择器固定240px；复选/开关右对齐；路径/命令最大440px，可选择、可换行；文本区自然增高。操作按钮按文字内容宽，不将单个输入拉满 |
| 对话框 | 普通宽560px、含长路径/操作详情宽720px；最大高为可见内容区减96px；内容内边距24px，动作区间距8px、上下16px，正文内部滚动 |

Qt 原生窗口装饰不由仿造按钮覆盖。已有最小窗口/收起侧栏/文字大小偏好保留；本轮仅以1080P截图检验当前布局，不新增其他尺寸测试承诺。滚动只在表格、性能内容、设置内容或对话框正文内发生，不能把命令栏、表格表头与底部确认按钮滚出可见范围。

## 5. 共用组件与状态

### 导航、搜索与命令

导航默认透明、无按钮描边；hover/press 为中性色。选中项使用中性 `hover` 底、主文本/图标及左侧3px蓝指示（高16px、圆端），选中不改变宽度/内边距。keyboard focus 另画2px focus环；收起后提供中文可访问名和工具提示，设置仍在底部。装饰图标不重复播报，图标按钮有名称、可用性和选中/展开状态。采用一致20px轮廓图标，数据真实应用图标保留原样，不以 emoji 替代。

共用搜索有可见“搜索”标签、搜索图标/清除入口与适用当前页的提示；不靠 placeholder 充当名称。保留当前输入、焦点与既有搜索口径。单页唯一标题左对齐，计数用普通次级文字；右侧主动作最多一个蓝色填充，其余中性描边或透明命令。结束/接管等破坏性动作在普通页保持中性或 danger 文本，进入明确确认后才显示相应确认动作。不能以新增大标题/横幅挤掉数据首屏。

### 表格与详情

表面为白色、无全网格重边框；表头 `surfaceSubtle`，底部1px分隔。数值右对齐，名称/状态/路径左对齐；排序箭头与文字一致，保留全部列排序、列宽拖动/菜单键盘替代、原始数值排序及未知值双向末尾。列标题、单位和资源总览层次明确。选择态覆盖热度，但焦点独立清晰；hover不冒充选中，不周期闪烁行。

名称显示真实图标与文字；长名称/路径省略后鼠标与键盘均可获得完整值，详情可选择/复制。未知用“—”并有可读原因；状态以文字+必要图标表示。业务“已禁用”是正常信息，不把整行设置成 disabled。详情沿用现有 Tab/章节，使用相同表格/事实/状态角色，不增设另一套视觉。

### 设置与表单

以 QWidget/QFrame + 布局组织设置卡片，替代通栏重边框 QGroupBox 和会把输入拉满的无约束 QFormLayout。卡片内部为20px图标、标题/可换行说明、右侧限宽真实控件；无需操作的状态信息保持可选择文本。没有点击行为的整卡不得画成可点击或得到按钮焦点。只在真实可展开内容上显示箭头，整卡点击不能误触旁边开关/按钮。

输入使用轻上/侧轮廓和 `strokeKeyline` 底边，focus以2px蓝边/底线反馈，error在字段下展示文字与danger图标。外部依赖/权限失败在对应卡片显示，不跳到无关页面；错误后保留原输入。偏好保存失败不得显示已保存；读取时不先填假默认值再覆盖。

### 对话框、菜单与反馈

原生模态对话框有清晰标题、目标身份、影响说明与动作区。危险操作初始焦点放取消，Esc取消；成功必须由后端真实确认，再关闭并显示结果。失败保留对话框和可读原因；busy防止重复提交，遵守既有不可中断阶段，不能伪装取消已接受的系统动作。关闭后焦点回到发起控件或安全替代控件。菜单目标在打开时固定，右键与Shift+F10/菜单键等效，方向键、Enter和Esc完整可用。

InfoBar 只用于暂停、冻结、失败、过期、部分读取等当前条件，图标+简短状态+原因/恢复动作，不常驻技术链路横幅。普通连接详情放“采样状态”。成功提示保持约4秒，可关闭；错误不自动消失到无法读取，不抢搜索焦点。布局预留/稳定复用反馈区域，刷新不抖动。

| 状态 | 必须可见行为 | 业务约束 |
|---|---|---|
| hover / pressed | 中性/蓝色对应状态色，位置尺寸不变，点击反馈≤100ms | 不因纯hover执行动作 |
| disabled | 真正不可交互、文本降强调，说明原因 | 不用disabled表现启动项已禁用/进程受限字段 |
| focus | 独立2px focus环，Tab顺序符合视觉顺序，完整可见 | 不被表头、InfoBar或弹层遮住 |
| busy | 按钮文字“正在…”/真实进度，禁止重复提交；其他页面可读 | 不阻塞GUI采样，不自动重试系统写入 |
| warming / unknown | “正在预热”/“—”+具体原因，已有数据按来源时刻显示 | 不伪造零值、进度或填满曲线 |
| empty | 区分真实无数据与搜索无结果，后者提供清除搜索 | 失败不显示“暂无数据” |
| paused / frozen / stale / offline | 明确区分暂停采集、冻结展示、过期、断连；展示最后成功时间和恢复入口 | 恢复追加真实新点，不补造间隔 |
| success / failure | 真实结果文字、语义图标与色，失败保留恢复办法 | API接受请求不等于动作完成 |

动效仅用于可中断的状态反馈，默认100～150ms颜色/透明度过渡；不做整页入场、表格闪烁、缩放按钮或装饰性循环动画。关闭系统动画/降低动态效果时使用最终静态状态，busy仍有文字或真实进度。

### 图表

白底、轻网格、蓝色主实线与深灰次虚线；线宽2px，小曲线可1.5px。当前值、单位、图例与来源时间明确，图例同时用线型和文字；轴标签为caption/secondary。只画真实样本与实际时间；预热/断流不补点。CPU逻辑处理器图保持原始组/索引、0～100%范围与可见模式选择；双击有键盘等效。磁盘仅保留读取/写入吞吐及设备事实，不恢复活动时间。HWiNFO不造资源小曲线，保持可用性与原始传感器单位。
