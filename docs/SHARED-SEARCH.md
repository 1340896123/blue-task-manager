# 顶部共用搜索

日期：2026-10-23。用户要求：顶部搜索输入共用，切换每个页面时自动执行搜索。此增量覆盖全部八页，取代历史“每页各自记住搜索”和性能/设置禁用搜索的约定。

## 研究与根因

- 已读取 React 官方 GitHub [Sharing State Between Components](https://github.com/reactjs/react.dev/blob/main/src/content/learn/sharing-state-between-components.md) 的 `Filtering a list` 解答：共同父级拥有唯一 query，输入与派生结果共享它。采用现有 React 机制，不新增依赖或协议。
- 已读 UI/UX Pro Max，定向查询 `search no results --domain ux`；采用明确无匹配说明与清空恢复路径，沿用当前设计 Token。
- 当前 App 输入绑定 `preferences.page(page).query`，输入仅更新当前页；切页恢复各页旧词。性能/设置被显式禁用，组件也不消费 query。
- ProcessWorkspace、PageWorkspace 与 Services 已有真实快照过滤；跨页定位和重置也写 query，必须统一路由。

## 共用行为合同

1. 全应用只有一个有效搜索词。八页顶栏文本相同；输入后即时过滤，切页立即应用当前词，无需 Enter、刷新或再次输入。
2. 搜索只派生现有真实数据，不增加采样、枚举、服务动作或搜索请求；保留暂停、冻结、离线与未知值语义。
3. 输入最多 256 字符，显示保留原文本，匹配沿用去首尾空白、大小写不敏感规则；已有纯数字 PID/会话 ID 精确匹配不变。
4. 改词时重置所有页面结果滚动位置；词未变时允许恢复该页滚动。排序、额外筛选、列、树模式和资源偏好继续独立。
5. 清空按钮清除共用词并归还焦点。Ctrl+F 在八页均聚焦共用输入；标签说明当前匹配范围。除偏好加载等真实状态外不按页面禁用。
6. 无匹配时有明确空态与清空/修改搜索提示；不显示无关图表、假数据或空白页面。旧选择被过滤后不能执行危险操作。

## 八页范围

| 页面 | 匹配范围与保留语义 |
|---|---|
| 进程 | 复用 processRows 的名称、PID、路径、发布者、用户名；数字精确 PID，保留树祖先上下文与身份保护 |
| 详细信息 | 同一进程查询，保留平铺、列、排序与身份选择 |
| 应用历史记录 | 名称/PID，数字精确 PID；仍为本次会话，已退出身份不可定位到复用 PID |
| 启动应用 | 名称、来源、命令/路径；只读，不执行命令或猜测启用状态 |
| 用户 | 用户名、会话名称、会话 ID；数字精确会话 ID，真实会话聚合不变 |
| 服务 | 既有服务名、显示名称、PID匹配；SCM真实状态与动作保护不变 |
| 性能 | CPU、内存、网络、磁盘、GPU类别及真实资源名称、描述、已显示标识 |
| 设置 | 现有区段标题、条目标签/说明、数据来源与能力文字 |

- 性能跨五类匹配：类别命中保留该类设备，设备命中显示所属类别与匹配设备；派生选择原偏好中的匹配项，否则首个匹配项。临时回退不覆盖资源偏好，清空恢复原选择；用户主动选择照常保存。
- 性能类别命中而设备未读到时保留预热/等待来源；完全无匹配显示空态。不以瞬时使用率搜索，不重置或补造曲线。
- 设置区段标题命中可展示整段，否则只展示匹配条目及必要标题；覆盖采样、桌面、入口接管、偏好、数据来源、能力。不可用条目仍可搜出并保留原因。
- 入口接管保留完整操作块和安全说明；筛选不得反复卸载重挂有读取/忙/确认状态的组件，不重复读取、关闭确认或执行设置动作。旧“每页搜索”帮助及重置说明同步为“共用搜索”。

## 状态与导航

- 在 usePreferences 集中维护唯一查询，使 page(page) 返回共享值，统一处理 updatePage 中的 query；不得用多个组件状态互相同步。
- 沿用600ms合并保存、关闭flush、JSON.NET校验与原子落盘。可增加可选顶层 searchQuery：旧配置缺省时从 pages.processes.query 迁移，否则为空；显式新空值不能被旧页面词覆盖。仍拒绝超长/NUL输入。
- 重启、重新读取偏好恢复共用词；恢复默认清空共用词，保留已有采样/窗口等边界，保存失败继续明确提示。
- 服务/历史/父进程/新任务定位进程：共用词改为真实目标PID，清除原进程额外筛选；进程定位服务：改为服务名；用户查看会话：清空共用词并沿用会话筛选。
- locateRequest须消费后失效；ProcessWorkspace重挂或后续手动切页不能重放旧PID并覆盖新词。
- 页内重置清除共用词，重置该页既有排序/筛选/选择；其他页除共用词与结果滚动外的偏好保留。

## 验收

| ID | 必验结果 |
|---|---|
| S01 | 同一词切遍八页，文本不变，立即匹配或明确空态；任意页改词后其他页使用新词 |
| S02 | 真实测试PID在进程/详细信息/历史精确匹配；服务、启动、用户沿用既有真实字段 |
| S03 | 性能能搜类别与实际设备名称；清空恢复资源偏好；不存在硬件记录不适用，不造设备 |
| S04 | 设置能搜采样、置顶、任务栏入口、偏好、来源、能力；输入不执行动作或重复读取 |
| S05 | 清空、Ctrl+F、滚动、排序/列偏好、冻结/暂停与危险操作选择回归正确 |
| S06 | 所有跨页定位/页内重置更新共用词；普通切页不重放旧定位 |
| S07 | 保存、重启、重新读取、旧配置兼容、恢复默认符合共享合同，使用独立测试偏好目录 |
