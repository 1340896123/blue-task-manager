# 白色简约图表配色

日期：2026-10-27。用户要求优化所有图表配色，采用白色简约风格。当前业务图表共用性能页 `Chart`：CPU总体、逐逻辑处理器、内存、磁盘读取/写入、网卡接收/发送、GPU，以及左侧资源磁贴小曲线。HWiNFO继续使用真实传感器表，不增加无来源图表。

## 1. 视觉与 Token

图面统一为纯白，网格和边界使用中性浅灰，主序列采用Windows蓝色实线，次序列采用深灰虚线。图例、取样点、大小曲线使用同一序列颜色。保持现有尺寸、线宽、时间轴、单位和真实数据缺口；图面使用无填充线条，不增加渐变、阴影或装饰面积。

| 角色 / Token | 当前值 | 使用范围 |
|---|---|---|
| 图面 / `--color-surface` | `#FFFFFF` | 全部主图、逐CPU小图、磁贴小曲线；选中磁贴内仍为白色 |
| 主序列 / `--color-chart-line` | `#0067C0` | CPU、内存、GPU；磁盘读取、网卡接收；对应点与图例实线 |
| 次序列 / `--color-chart-secondary` | `#58636F` | 磁盘写入、网卡发送；对应点与图例虚线 |
| 网格 / `--color-chart-grid` | `#ECEFF2` | 所有有网格的主图、逐CPU图 |
| 图面边界 / `--color-border` | `#E5E5E5` | 主图和小曲线的中性边界；替换小曲线原蓝色边框 |
| 标签 / `--color-text-secondary` | `#5F5F5F` | 轴、单位、图例文字、预热/等待说明 |

颜色集中定义在全局CSS Token，图表组件通过变量读取。图面与表格热度分离，表格已有 `--color-heat-*` 继续表达真实资源热度。页面外壳、选中、焦点与状态语义继续使用现有Windows Token。

WCAG相对亮度公式测得与白底的对比度：主线 **5.674:1**、次线 **6.124:1**、标签 **6.385:1**。曲线保持不透明，图形关键线条满足3:1、正常标签文字满足4.5:1。浅灰网格和图面边界是辅助参照，不承担唯一数据、状态或交互边界；读数、图例、线型和焦点仍明确。

## 2. 可访问性与数据行为

磁盘和网卡保留两个明确的序列名称、实线/虚线图例及当前数值，不能仅靠颜色区分。单点、预热、null、断流、暂停和资源不存在继续采用已有状态；配色不改变曲线点、缩放、历史上限、独立来源时间、API或原生采样。磁盘仍只显示读取/写入吞吐，D08已移除的活动时间UI继续移除。

逐CPU图、小曲线和大图共享本组颜色。资源磁贴的选中底色、键盘焦点与文字仍可辨认；白色图面不覆盖焦点。按Windows桌面尺寸检查，不扩展暗色主题或移动端页面。

## 3. 设计依据

用户指定的UI/UX Pro Max定向 `chart` 检索命中“Trend Over Time”：时间序列使用线图，多序列采用不同颜色、线型和直接标签，保留可读数值。`color` 初次结果偏向其他产品，收窄后仍不适用本项目既有Windows蓝色体系，未套用整套外部调色板。React专项检索两次无结果，实现沿用当前组件与通用图表建议。现有MASTER是颜色与尺寸的唯一来源，本次只更新图表角色。
