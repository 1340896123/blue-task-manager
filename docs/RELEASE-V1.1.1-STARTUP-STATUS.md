# 1.1.1 预览构建：启动应用真实状态

2026-10-28。沿用 `1.1.1` 应用版本，现有发布工作流默认生成新的 `v1.1.1-build.<运行序号>` 预览标签。具体标签、源码提交与下载附件以对应 [GitHub Release](https://github.com/1340896123/blue-task-manager/releases) 为准，不覆盖既有版本。

## 本版修复

- 修复启动应用整列固定显示“无法确定”：通过真实 Windows Run、32位 Run 和 Startup 文件夹的批准记录显示已启用或已禁用，保留各来源独立身份。
- 状态列使用真实值排序，未知项始终放在最后；已打开的启动项详情会随真实来源刷新而更新。
- 仅解释格式有效的 Windows 启用/禁用记录（状态2/3）。未知、损坏、读取失败、跨范围冲突及 RunOnce 仍显示明确原因；缺失批准记录按默认启用口径说明，不承诺程序最终执行成功。
- 状态读取保持只读。需要更改启动状态时使用已有“Windows 启动应用设置”入口，本版不增加启动项启用/禁用写接口。

本版同时包含前轮[磁盘型号、类型与总线信息、读写吞吐和白底性能图表](RELEASE-V1.1.1-DISK-CHARTS.md)。

## 验证与下载

本机生产采集器、真实 API、浏览器及正式 Electron 共通过514项断言，其中启动状态专项114项、已有回归及桌面基线400项；22个已有启动来源与独立注册表读取一致。测试仅修改GUID专用启动项，结束后专用注册值、快捷方式与所测端口残留均为0。具体来源、构建散列、截图和未执行分支见[启动状态验收记录](STARTUP-STATUS-RESULTS.md)。这些本机证据不能代替新安装包的发布验收。

发布须通过现有 Windows 工作流的自包含构建、安装/重装/卸载生命周期及真实 Electron 桌面检查，再由独立发布job核验源码提交、安装器 SHA256 和完整交付集。下载对应 Release 的 Setup.exe、`SHA256SUMS`、`acceptance.json` 和 `acceptance.md`；使用同一 Release 的校验文件核对安装包。流程见[手动安装包说明](MANUAL-INSTALLER-BUILD.md)。

Windows x64 安装包内置 .NET 10、ASP.NET Core 和 Electron，安装与运行需要管理员权限，安装器尚未数字签名。未知状态的保留不代表已验证其 Windows Shell 语义；本轮没有修改用户组策略或现有状态键ACL来扩大覆盖率。
