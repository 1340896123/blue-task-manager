# 本机快照持续流量修复

日期：2026-11-08。本增量只处理 Takao 自身持续回环通信的传输开销，不改变真实 Windows 网络采集口径。

## 已确认原因

- 当前 Qt `MainWindow::poll` 每500毫秒读取 `/api/snapshot`；Host每个新采样发布完整JSON，包含全进程、全部会话历史、120点性能历史及其它页面数据，条件请求只能避免同版本重复体。
- 当前实际连接只有 Host `127.0.0.1:5188` 与 Qt 本机临时端口的成对连接。`Program.cs` 只监听回环；两进程相同网络速率符合一端发送、另一端接收的本机传输。此观察不等于对进程全部生命周期外联的承诺。
- 只读实测完整快照 identity 为1,617,018字节，协商gzip为257,551字节。Host压缩正常；Qt网络栈默认协商并自动解压，不能以手写 `Accept-Encoding` 破坏该行为。约每1.1秒传一次完整gzip表示即可产生截图约238KB/s的速率。
- ETW进程网络计入Windows报告的回环和虚拟网络，而性能页网卡使用真实硬件接口。因此截图中的数字不等于互联网下载速率；不得通过隐藏Takao进程、扣除猜测字节或把未知改0来“修复”。
- 更新服务成功检查后间隔6小时，失败至少退避15分钟；设置读取更新缓存不会逐次访问GitHub。当前证据指向快照传输，不能把它归因于持续检查更新。

## 最小实现合同

1. 保留标准回环HTTP/JSON.NET、gzip和弱ETag。默认无query的 `/api/snapshot` 继续返回原完整合同，供现有调用、按需完整冻结快照与兼容验收使用。
2. 增加明确白名单的标准HTTP查询投影：`view=live|history|performance`。`live`不传会话历史和性能历史；`history`只补会话历史；`performance`只补性能历史。其它现有字段、进程完整身份、状态、原因和时间保持，避免跨页进程定位及动作重新引入身份错误。未请求的历史不应被客户端当作真实空来源。
3. 每个表示按实际revision和view缓存序列化结果，并使用彼此不同的弱ETag；不能让live的条件请求导致history/performance错误304。设置、暂停、历史重置、警告和Host实例变化仍使相应表示失效；缓存只有固定少量投影，不能按任意query无限增长。非法view返回明确400。
4. Qt进程/详细信息及其它普通页面使用live，应用历史使用history，性能使用performance。切页立即请求当前view；只允许一个在途快照读取，旧view迟到响应不能应用到新页面或污染新view的ETag。新页数据到达前保留明确加载/上一有效快照状态，不显示“0项”假空；成功后恢复原查询、列宽、选择与滚动语义。
5. 正常轮询匹配实际1/2/5秒采样周期；暂停时至少5秒慢轮询，恢复采样立即补最新。手动刷新和动作结果仍可立即请求，不降低Host真实采样频率，不更改采样间隔偏好。维持同一client最多一个在途请求及条件304保留数据。
6. 冻结显示需要一份完整真实快照，保证冻结后切至此前未打开的历史/性能页仍是同一时刻的数据。只在完整读取成功后进入冻结；读取失败给既有可读错误并允许重试，不能冻结一份缺字段数据。后台继续采样及按页读取；取消冻结安全展示当前页最新有效数据。
7. 不新增页面、布局、网络口径文案或视觉Token；必要的加载、错误、冻结和暂停复用现有页头状态文字。不改变ETW解析、更新检查周期、最小化行为、压缩级别或安装器，不引入命名管道或私有差分协议。

## 定向验收

沿用 [ACCEPTANCE.md](ACCEPTANCE.md) 的变更范围约束及PRODUCT-V1.1 U11的HTTP/冻结规则，仅运行以下直接相关检查：

| ID | 验证 | 通过条件 |
|---|---|---|
| LT01 | Host Release和Qt相关目标构建 | JSON.NET及原平台边界保持；只扩展本次受影响目标。 |
| LT02 | 专用真实Host API：完整/三投影、gzip、ETag/304 | 同revision共同字段一致、历史只在对应投影；gzip体积对照可复现；跨view不错误304、同view304空体；非法view400，暂停/周期/重置使缓存正确失效。 |
| LT03 | 原生Qt真实链路：快速切进程→历史→性能→进程，含在途切页 | 无漏表、假空或迟到覆盖；真实来源与身份保持；原有动作依赖的进程数据仍存在。 |
| LT04 | 1/2/5秒、暂停/恢复 | 请求次数匹配合同，最多一个在途；恢复立即补帧，Host采样保持设定周期；304不清表或断线。 |
| LT05 | 冻结后切历史/性能、取消冻结及失败恢复 | 冻结各页同一真实快照，后台sampleId继续前进；取消后最新当前页可用，不将缺数组显示为空数据。 |
| LT06 | 同机实际快照传输对照 | 记录进程数、会话历史数、历史点数、窗口状态、周期及gzip完整/live体积。预期本机live体积约为原完整一半；报告实际数值，不把剩余必要回环流量宣称为0或外网流量。 |

运行时结果、可重现命令及必要截图路径另记 `LOCAL-SNAPSHOT-TRAFFIC-RESULTS.md`；不保存完整机器进程快照或令牌，不结束用户既有Takao实例。界面如需截图只在1920×1080环境执行。
